# QA Automation Classwork

This repository contains coursework, exercises, and practice projects
completed as part of a QA Automation class.

## Purpose

The goal of this repository is to document learning progress and
practice software testing concepts, test automation techniques, and
supporting tools.

## Contents

As the course progresses, this repository may include:

-   Manual testing exercises and test cases
-   Test plans and test documentation
-   Automation scripts and automated tests
-   Programming exercises used in test automation
-   API and UI testing practice
-   Notes, examples, and other class assignments

## Tools and Technologies

The tools and technologies used will depend on the topics covered in
class. Examples may include Python, Playwright, Git, and testing tools
introduced during the course.

## Repository Structure

Coursework will be organized into folders by topic, lesson, or
assignment as the repository grows.

## Disclaimer

This is a learning repository for educational purposes. The code and
examples may be works in progress and are not necessarily intended for
production use.
